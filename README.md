# «Больница»

Рабочее название. Управленческий симулятор больницы и врача для ПК (Steam): строите
отделения, нанимаете персонал, принимаете поток пациентов — и, если хотите, сами ведёте
случай от вопросов до диагноза. Медицина — настоящая, из клинических рекомендаций и
учебников, с источниками; модель и база — из игры студии «Анамнез».

Делает студия «Горница» (gornitsa.games), выходит под отдельной маркой (решение владельца
от 16.10.2026). Правила студии — в уставе
[`Nefeste/gornitsa`](https://github.com/Nefeste/gornitsa).

Где проект сейчас — [`STATUS.md`](STATUS.md). Документы — [`docs/`](docs/README.md).

## Как запустить

Появится с первым кодом (пробы, [`docs/specs/2026-10-prototype.md`](docs/specs/2026-10-prototype.md)).

Версий ещё нет. Первая — прототип для игры владельца.
