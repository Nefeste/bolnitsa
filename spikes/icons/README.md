# Проба: значки — кандидаты

**Вопрос** ([`docs/specs/2026-10-aaa-polish.md`](../../docs/specs/2026-10-aaa-polish.md), «По этапам среза», 5): какой
набор значков одной руки предложить владельцу вместо символов Юникода и эмодзи в окне — с открытой лицензией, медицинскими
значками и в пару к шрифту IBM Plex Sans (#107).

**Коротко.** Четыре набора с npm: Carbon (IBM, Apache 2.0), Lucide (ISC), Tabler (MIT), Phosphor (MIT); нужные игре
значки есть во всех. Рекомендация — Carbon: та же система дизайна, что и Plex. Отчёт и лист сравнения —
[`docs/reports/2026-10-icons.md`](../../docs/reports/2026-10-icons.md).

## Что здесь

- `fetch.sh` — наборы с npm (`npm pack`, без установки и скриптов пакетов), версии закреплены → `files/` (не в git).
- `sheet.mjs` — лист сравнения: верхняя полоса, левые инструменты, кнопки, строки целей и предупреждений и сетка всех
  значков в каждом наборе, со шрифтом и цветами игры (`app/index.html`) → `docs/reports/2026-10-icons/sheet.png`.
  Страница листа — в `files/` (в ней значки наборов), в отчёт — только снимок.

## Как повторить

```bash
bash spikes/icons/fetch.sh
node spikes/icons/sheet.mjs
```
