# Проба: гарнитура — кандидаты под SIL OFL

**Вопрос** (решение владельца #68, вариант 2; [`docs/specs/2026-10-aaa-polish.md`](../../docs/specs/2026-10-aaa-polish.md),
«Решения владельца», 1): какую свою гарнитуру предложить владельцу — с открытой лицензией, кириллицей, знаком рубля,
табличными цифрами и своим курсивом, плотную для карты больного и планёрки.

**Коротко.** Проверено двенадцать гарнитур из Google Fonts, все под OFL и с кириллицей. На снимках игры — четыре разные по
характеру: IBM Plex Sans, Golos Text, Manrope, Inter. Рекомендация — IBM Plex Sans; вопрос владельцу — #107. Отчёт, таблица и листы
сравнения — [`docs/reports/2026-10-fonts.md`](../../docs/reports/2026-10-fonts.md).

## Что здесь

- `fetch.py` — файлы шрифтов, `METADATA.pb` (авторы, лицензия, начертания) и `OFL.txt` из хранилища Google Fonts на
  GitHub (`google/fonts`, папка `ofl/`) → `files/` (не в git).
- `cover.py` — для каждой гарнитуры: знаки строк игры и медицинской базы (`src/i18n`, `src/ui`, `content/`), которых в
  ней нет; табличные ли цифры сразу или по признаку `tnum`; есть ли свой курсив; насыщенности; x-высота; ширина одной и
  той же строки карты и кассы (Inter — 100 %). Значки (☰, ⚙, 🏗) не в счёт — их заменят рисованные. Печатает таблицу
  отчёта.
- `shots.mjs` — три сцены игры в каждой из четырёх гарнитур: готовая больница в 09:30 на паузе — вкладка «Пациенты»,
  карта принятого и отпущенного больного; затем «До утра» — планёрка. Шрифт подменяется стилем страницы (`@font-face`
  с того же адреса — CSP игры пускает только свои файлы); игра не меняется → `shots/` (не в git).
- `compose.py` — листы сравнения: один участок экрана в четырёх гарнитурах, подпись — самой гарнитурой →
  `docs/reports/2026-10-fonts/`.

## Как повторить

```bash
cd spikes/fonts
python3 -m venv .venv && .venv/bin/pip install fonttools pillow
.venv/bin/python -I fetch.py
.venv/bin/python -I cover.py
cd ../.. && npm run build && node spikes/fonts/shots.mjs   # около 10 минут без видеокарты: «До утра» до планёрки
cd spikes/fonts && .venv/bin/python -I compose.py
```

Снимки сняты в контейнере агента без видеокарты (качество «среднее»); шрифты от этого не зависят.
