# 0001. ADR студии в первой ПК-игре: что действует, что нет, от чего отступаем

**Решили.** «Больница» — проект студии «Горница» под отдельной маркой (решение владельца
16.10.2026, №81 в `Nefeste/uprava`). Устав действует целиком, кроме мест, где он говорит о
телефонах и RuStore. Ниже — как каждый ADR студии применяется здесь.

| ADR студии | Здесь |
|---|---|
| 0001 устав в одном репозитории | действует |
| 0002 копирование вместо общего пакета | действует: движок и база «Анамнеза» — копиями с пометкой источника |
| 0003 Expo / React Native, APK в CI | **не действует.** Стек ПК-игры выбирают пробы; итог — ADR проекта «Стек» и ADR студии об отступлении, с решением владельца |
| 0004 чистый движок, снимки, вечные идентификаторы | действует |
| 0005 без сети по умолчанию, свой сервер | действует строже: сети нет совсем, сервера нет |
| 0006 вечный идентификатор и ключ подписи Android | не относится; для ПК — идентификатор игры в Steam и подпись установщика, решение — до страницы Steam |
| 0007 ключ устройства без учётных записей | не относится: нет сервера |
| 0008 минимум данных | действует: игра ничего не отправляет |
| 0009 деньги: RuStore Pay на телефоне | **не действует.** Игра продаётся в Steam целиком; ADR о деньгах — до страницы Steam |
| 0010 без давления | действует; пауза — в любой момент |
| 0011 честная игра с людьми | не относится: игра одиночная |
| 0012 контент из источников, без генераторов изображений | медицина и тексты — действует; изображения — исключение по решению владельца №77, действует после ADR студии с условиями |
| 0013 «Сени» | действует, когда появится почта поддержки марки |
| 0014 два региона | действует: игроки по всему миру, но ничего не уходит с компьютера игрока |
| 0015 страница игры на сайте студии | решит владелец вместе с маркой |
| 0016 профиль с 14 лет | не относится: профиля на сервере нет |
| 0017 видимость | действует: репозиторий закрыт |
| 0018 классы изменений, автослияние | действует |
| 0019 CI на PR, сборка на тег | действует: сборка ПК-версии — на тег |

**Почему.** Первая ПК-игра не должна молча выпадать из правил студии: всё, что не про
телефон, остаётся в силе, а каждое отступление записано и опирается на решение владельца.

**Платим.** Три решения ещё впереди — стек, деньги, изображения; до них прототип не берёт
генераторы изображений и не подключает Steam.

**Когда пересмотреть.** После проб (стек), до страницы Steam (деньги, идентификатор, подпись,
сайт), при первом использовании генератора (изображения).
