# 0003. Связь со Steam: достижения и облако через клиент Steam — ближе к 1.0

**Решили** (решение владельца 17.10.2026, #11, вариант 1):

- **Достижения и Steam Cloud — через клиент Steam** на компьютере игрока (библиотека
  `steamworks.js`). В Steam уходят только отметки достижений и файлы сохранений. Их
  синхронизирует сам клиент Steam по правилам Valve. Игра в сеть не ходит, студия этих данных
  не получает.
- **Подключаем ближе к 1.0** — на этапе Д ([`../specs/2026-10-v1.md`](../specs/2026-10-v1.md)).
  До этого всё работает локально: сохранения — файлы на компьютере игрока, к Steam игра не
  обращается. Демо на Next Fest тоже работает без Steam.

**Как** (план агента, уточняется на этапе Д):

- Со Steam говорит только главный процесс Electron (`electron/`), через один модуль. Окно и
  поток расчёта о Steam не знают.
- Клиента Steam нет — нет достижений и облака, остальная игра работает как прежде.
- Достижения, которые появятся до подключения, считаются и показываются в самой игре.
- Версию `steamworks.js` и его API берём из документации на этапе Д, не по памяти.

**Почему.**

- Игроки жанра ждут достижений и облака сохранений ([`../08-game-design.md`](../08-game-design.md), §16).
- Данных об игроке мы не собираем. В отметках достижений и сохранениях нет персональных данных.
- Синхронизирует клиент Steam: игрок пользуется им по своему соглашению с Valve. Так же сведения
  об оплате RuStore Pay уходят в RuStore по его правилам (устав, `docs/07-privacy.md`).
- Раньше этапа Д связь не нужна. До выпуска формат сохранений меняется, а достижения появляются
  вместе с кампанией и испытаниями.

**Платим.**

- До выпуска версии со связью надо внести два изменения: строку Steam в таблицу «Что может
  уходить» устава (`docs/07-privacy.md`) и раздел «Больницы» в политике на сайте.
- В сборке появится библиотека с машинным кодом; её надо проверить на Windows и Steam Deck.
- Сохранения прошлых версий должны загружаться и из облака — нужны миграции
  (`08-game-design.md`, §14).
- Это инженерная оценка, а не юридическая консультация.

**Когда пересмотреть.**

- Steam изменит правила для достижений или облака.
- Игра выйдет в другом магазине.
- В сохранениях появятся сведения о человеке.
