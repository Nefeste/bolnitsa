# Как ведётся работа

Общий порядок — в уставе студии
([`docs/04-process.md`](https://github.com/Nefeste/gornitsa/blob/main/docs/04-process.md)):
документы в репозитории, спецификация до кода, ADR, ветки `claude/…`, PR, CI на PR. Здесь —
только особенности «Больницы» как первой ПК-игры студии.

## Ветки, слияние, CI

- Работа — в ветках `claude/<задача>`, в `main` — через PR. Кто сливает — по классам
  изменений (ADR студии [0018](https://github.com/Nefeste/gornitsa/blob/main/adr/0018-change-classes-automerge.md));
  пути владельца — в [`.github/CODEOWNERS`](../.github/CODEOWNERS).
- Проверки на PR (`pr.yml`) появятся вместе с первым кодом: типы, тесты движка, тесты базы
  (ADR студии [0019](https://github.com/Nefeste/gornitsa/blob/main/adr/0019-ci-on-pr.md)).
- Сборка для ПК — только на тег версии `vX.Y.Z`, как APK у мобильных игр; ручного запуска
  нет. Тег ставит владелец. Workflow — [`.github/workflows/build.yml`](../.github/workflows/build.yml):
  Electron, Windows (zip и portable `.exe`) и Linux (AppImage и tar.gz) — всё на
  `ubuntu-24.04`, без wine; файлы — в релиз на тег, версии 0.x — пре-релизы. Тег сверяется с
  версией в `package.json`: `v0.0.2` при `0.0.1` останавливает сборку.
- Пока игры нет, собирается проба 3D-вида (`spikes/render-3d`, с версии `0.0.2`), версия — в
  её `package.json`; файлы релиза — `BolnitsaProbe3D-…`. Проба карты (`spikes/map-render`,
  `v0.0.1`) остаётся в репозитории, но больше не собирается. Установщика NSIS и своей иконки у
  `.exe` нет: без wine они не собираются (`spikes/map-render/README.md`, «Сборка»).

## Пробы

Код проб живёт в `spikes/<имя>/`, у каждой — свой `README.md`: что проверяли, как запустить,
что вышло. Итог проб — ADR проекта. Код проб в игру не переносится как есть.

## Копии из «Анамнеза»

Движок и медицинская база переносятся копированием (ADR студии 0002) с пометкой источника и
коммита в первой строке файла. Список копий находится поиском по строке `// из anamnez:`.
Исправление в скопированном — задача перенести его и в «Анамнез».

## Версии

По уставу. Первая версия — прототип для игры владельца; номер — `0.1.0`.
