# Что за игра

Рабочее название — «Больница». Имя игры и марки выбирает владелец (вопрос №85 в
`Nefeste/uprava`).

## Коротко

Управленческий симулятор больницы с настоящей медициной. Игрок строит больницу на плане
сверху, нанимает персонал и принимает поток пациентов. Нанятые врачи ведут случаи сами, по
своим навыкам; игрок в любой момент может открыть любого пациента и провести случай сам —
вопросы, осмотр, обследования, диагноз, лечение. Ошибка диагноза имеет последствия.

Платформа — ПК (Windows, Linux и Steam Deck), магазин — Steam. Игра одиночная и работает без
сети.

## Для кого

- Игроки управленческих симуляторов, которым мало «весёлой» медицины: им важно, чтобы болезни,
  обследования и решения были похожи на настоящие.
- Те, кто любит разгадывать случаи: режим врача — головоломка с неполной информацией.

## Чем отличаемся

- **Настоящая медицина с источниками.** Модель и база «Анамнеза»: болезни, признаки,
  обследования и лечения из клинических рекомендаций и учебников, у каждой записи — источник.
- **Режим врача** — не мини-игра, а полный приём из «Анамнеза».
- **Системы, а не графика**: поток, очереди, навыки, ошибки и их последствия честно
  просчитаны движком.

## Чего нет сознательно

- Сети, учётных записей, сбора данных об игроке (ADR студии 0008).
- Доз и торговых названий лекарств (правила медицинской базы «Анамнеза»).
- Мультяшных выдуманных болезней.
- Таймеров ожидания, энергии, давления на игрока (ADR студии 0010). Пауза — в любой момент.

## Словарь

| Слово | Что значит |
|---|---|
| Больница | вся карта игрока: помещения, оборудование, люди |
| Помещение | комната с назначением: регистратура, кабинет врача, палата… |
| Случай | один пациент от прихода до выписки |
| Режим врача | игрок сам ведёт случай вместо нанятого врача |
| Смена, день | единица времени игры; пауза — в любой момент |
| Движок | чистый TypeScript без интерфейса: состояние, команды, течение времени |
| Медицинская база | записи болезней, признаков, обследований, лечений — из «Анамнеза» |
